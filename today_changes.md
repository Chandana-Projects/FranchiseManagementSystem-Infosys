# Summary of Changes

Today we upgraded the franchise system with machine learning features, simulation tools, real-time alerts, advanced settings configuration, and containerization setup.

- What-If Simulation Sandbox: Users can simulate changing discount rates and marketing spend to predict future franchise revenue.
- Live POS and Anomaly Ticker: Displays live transaction activity and flashes notifications when machine learning models flag transaction anomalies.
- Model Retraining Console: Displays model accuracy metrics and allows retraining core models directly from the system console.
- Gemini AI Chat Agent: Integrates real Gemini API keys to provide business advice based on current franchise performance metrics.
- Preferences Settings Page: Configures colors, glow effects, database resilience fallbacks, model parameters, and logs activity in a terminal.
- Docker Orchestration: Configured Docker files and Docker Compose to containerize the database, express api, machine learning microservice, and next.js web application.
